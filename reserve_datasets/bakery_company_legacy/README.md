# Reserve Dataset: Legacy Bakery Company (Separate Reference)

This directory contains legacy benchmark data from a separate commercial bakery company.
It is **strictly isolated and archived** to ensure it is never mixed with the primary RMIMS enterprise dataset.

### Separation Notice:
- **RMIMS Primary Enterprise:** 28 Authentic Philippine Pasalubong Finished Products (Coco Jam, Banana Chips, Chicharon, Chili Garlic, Ube Halaya, Atsara, etc.) across 59 Master Raw Materials (`RM-001` to `RM-059`).
- **Legacy Bakery (Reserve):** Standalone archive for academic/benchmarking reference only.
