RMIMS USER-SIDE INTEGRATION UPDATE
===================================

This package keeps the Admin updates from RMIMS-Admin-Updates-FINAL.zip and
updates the User side from RMIMS-Material-Activity-EdgeCases (1).zip.

Included User-side updates:
- Dashboard
- Inventory
- Material Activity
- Analytics
- Reports
- Settings
- User-side JavaScript and isolated CSS files

Important integration change:
User Material Activity now reads the Admin's finished_products and
product_material_requirements tables instead of creating a second products /
product_materials data model.

It also records:
- usage_records.product_id
- usage_records.product_name
- usage_records.created_by
- stock_receipts.created_by

SQL:
Run supabase/USER_MATERIAL_ACTIVITY_MIGRATION.sql in Supabase SQL Editor
after schema.sql and material-activity-schema.sql.

Do NOT run the reset/backup SQL just for this User-side update.
