SUPABASE SETUP
--------------
Use the Supabase SQL Editor.

If your existing RMIMS schema is already installed, run:
  supabase/ADMIN_SETTINGS_MIGRATION.sql

This should be run after the existing RMIMS:
  schema.sql
  user-management-schema.sql
  material-activity-schema.sql

The SQL file is a migration only. It does not reset your data when you install it.

The Data Reset and Restore functions are only executed later when an Admin
uses the corresponding Settings actions.

IMPORTANT
---------
Keep your Supabase URL and anon key configured in:
  RMIMS/supabase/supabase-config.js

Do not place a Supabase service-role key in the browser/client files.
