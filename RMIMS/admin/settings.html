System Maintenance & Factory Reset

Root administration control • Restore system to factory brand-new state.

Factory Resetting the System will restore RMIMS to a completely brand-new, clean state. This operation wipes all transactional history, recorded stock movements, activity trails, and temporary registrations across all branches, while preserving the master catalog.
Data Cleared (Brand-New State):
  • All Stock Receipts (Receive module records)
  • All Material Disbursements (Used/Disburse records)
  • All Staff activity logs & submission drafts
  • All Manager operational activity records
  • Pending account requests awaiting approval
  • Cached AI forecasting models & predictions
Data Restored & Protected:
  • Root Administrator credentials preserved
  • Core 59 authentic raw materials restored to pristine baseline
  • Branch store location definitions intact
  • Standard directory user roles intact
Authority: Root Administrator Only

Manager and Staff roles cannot access this factory reset function.
